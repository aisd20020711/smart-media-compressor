# 智能影音圖片壓縮器（Media Compressor）

一個基於 Python `tkinter` 打造的桌面端影音與圖片壓縮工具，整合 **Pillow** 進行圖片轉檔與壓縮，並透過 **PyAV** 單一 `demux` 流程同步處理影片與音訊串流，輸出相容性高的 MP4（H.264 + AAC）與 WebP 檔案。

---

## 功能特色

- **自動偵測檔案類型**：選取檔案後自動判斷為圖片或影片，並提示對應的輸出格式與壓縮設定。
- **圖片壓縮與格式轉換（Pillow）**：
  - 支援 `.jpg`、`.jpeg`、`.png`、`.webp`。
  - 自動依據 EXIF 方向校正旋轉（`ImageOps.exif_transpose`）。
  - 透明背景（`RGBA`、`LA`）自動合成至白色底色後轉為 `RGB`，再輸出為 WebP（`quality=85`、`method=6`）。
- **影片與聲音同步壓縮（PyAV）**：
  - 支援 `.mp4`、`.mkv`、`.mov`、`.avi`、`.webm`、`.m4v`、`.flv`。
  - 單一 `demux` 同時讀取影像與音訊封包，影像編碼為 **H.264（`libx264`、`yuv420p`、`preset=fast`）**，音訊經 `av.AudioResampler` 轉為相容格式後編碼為 **AAC（128 kbps）** 封裝至 MP4。
  - 提供三段影片壓縮品質選擇（**高品質 CRF 23**、**一般 CRF 28**、**高壓縮 CRF 32**）。
- **背景執行緒與即時進度**：壓縮作業於背景執行緒執行，避免介面凍結，並即時更新進度條與壓縮前後檔案大小／縮減比例。

## 環境需求與安裝

- Python 3.9+（建議搭配支援 `tkinter` 的官方 Python 發行版）

安裝相依套件：

```bash
pip install pillow av
```

> **提示**：`av`（PyAV）內含 FFmpeg 函式庫，在多數作業系統上可直接透過 `pip` 安裝；若在特定 Linux 發行版遇到編譯問題，可先安裝系統層級的 FFmpeg 與開發函式庫。

---

## 使用方式

1. 執行主程式：

```bash
python main.py
```

> 請將 `main.py` 替換為你實際儲存程式碼的檔名。

2. 點擊 **「瀏覽檔案」** 選擇支援的圖片或影片。
3. 若為影片，可在 **「影片壓縮品質」** 下拉選單選擇 `高品質`、`一般` 或 `高壓縮`（預設為 `一般`）。
4. 點擊 **「開始壓縮」**，等待進度達 `100%` 後即可查看壓縮結果與輸出檔案路徑。

---

## 輸出檔案命名規則

壓縮後的檔案會儲存在**與原始檔案相同的資料夾**中，檔名加上後綴：

- **圖片輸出**：`<原檔名>_compressed.webp`
- **影片輸出**：`<原檔名>_compressed.mp4`

## 已知限制與注意事項

- **單檔處理**：目前每次僅支援壓縮單一選取的檔案。
- **覆蓋提醒**：若目標資料夾已存在同名的 `*_compressed.webp` 或 `*_compressed.mp4`，壓縮完成時將會直接覆蓋。
- **無音訊來源**：若原始影片本身不包含音訊串流，仍會正常輸出 H.264 影片，並在完成時提示無音訊。
